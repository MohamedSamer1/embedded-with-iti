# 📖 Overview

Welcome to my **Linux & Ubuntu** learning repository.

This folder contains my tasks, assignments, scripts, and practical exercises completed throughout the **ITI Embedded Systems Track**.

It documents my journey in understanding Linux as a development environment for embedded systems, starting from basic command-line usage and system concepts to writing shell scripts, managing processes, and working with essential Linux tools used in embedded software development.

The goal of this repository is not only to store solutions, but also to demonstrate the learning process and hands-on practice with Linux-based systems.
