A beginner-friendly Linux lab that introduces the essential command-line skills required to work efficiently in a Linux environment. This lab focuses on navigating the filesystem, creating directories and files, reading file contents, and understanding the structure of a Linux system using the Bash shell.

The objective of this lab is to build a strong foundation in Linux before moving on to shell scripting, system administration, networking, and embedded Linux development.

---

# ✨ Lab Objectives

- Install Ubuntu Linux
- Navigate the Linux filesystem
- Understand the Linux directory hierarchy
- Create directories and files
- Use common navigation commands
- Read and inspect file contents
- Practice working with the Linux terminal

# 🛠️ Commands Practiced

| Command | Description |
|---------|-------------|
| `pwd` | Print the current working directory |
| `ls` | List directory contents |
| `ls -la` | List all files including hidden files |
| `cd` | Change directory |
| `mkdir` | Create directories |
| `touch` | Create empty files |
| `cat` | Display file contents |
| `head` | Display the first lines of a file |
| `tail` | Display the last lines of a file |
| `cp` | Copy files and directories |
| `mv` | Move or rename files |
| `rm` | Remove files |
| `rmdir` | Remove empty directories |
| `find` | Search for files and directories |
| `tree` | Display the directory hierarchy |

# 📦 Filesystem Hierarchy Overview

Some important Linux directories explored during this lab:

| Directory | Purpose |
|-----------|---------|
| `/` | Root directory |
| `/home` | User home directories |
| `/etc` | System configuration files |
| `/usr` | Installed applications and utilities |
| `/var` | Variable data such as logs |
| `/tmp` | Temporary files |
| `/dev` | Device files |
| `/proc` | Process and kernel information |
| `/boot` | Bootloader and kernel files |
