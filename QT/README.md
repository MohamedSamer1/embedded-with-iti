# 📖 Overview

Welcome to my **Qt Framework** learning repository.

This folder contains my tasks, assignments, examples, and practical exercises completed throughout the **ITI Embedded Systems Track**.

It documents my journey in learning Qt as a powerful framework for developing cross-platform applications, with a focus on graphical user interfaces (GUI), event-driven programming, and embedded software applications.

The repository covers my progress from understanding Qt fundamentals and project structure to building interactive interfaces using **Qt Widgets**, **QML**, and modern Qt development tools.
